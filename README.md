# Limpopo Hitch Connect (African-Hitch)

A real-time ridesharing and hitchhiking platform built specifically for commuter routes across Limpopo Province and surrounding transport corridors in South Africa.

## 🚀 System Architecture

- **Frontend (`limpopo-hitch-main`):** React 19, TypeScript, TanStack Start & Router, Tailwind CSS, MapTiler GIS SDK, Socket.io Client, Radix UI.
- **Backend (`limpopo-hitch-backend`):** Node.js, Express.js, TypeScript, Socket.io Server, Prisma ORM, SQLite.
- **Core Capabilities:** Real-time driver/hiker matching, GPS telemetry tracking, redlisting & safety moderation, DAC administrative governance portal.
